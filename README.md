# scoop-bucket

A [Scoop](https://scoop.sh) bucket.

```console
$ scoop bucket add zet235 https://github.com/zet235/scoop-bucket
$ scoop install caffeinate
$ scoop install caps-as-shift
```

## Contents

| App | Description |
|---|---|
| [caffeinate](https://github.com/zet235/caffeinate) | Keep Windows awake, from the tray or the command line |
| [caps-as-shift](https://github.com/zet235/caps-as-shift) | Remap Caps Lock to Left Shift, from the Windows tray |
